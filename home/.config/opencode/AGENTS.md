# Dotfiles first

For any question or task involving configuration on this machine, inspect the relevant files under `$HOME/.dotfiles` before answering or editing. This includes OpenCode, Zsh, Ghostty, Starship, tmux, Git, Neovim, and other command-line tools. Treat the managed dotfile as the source of truth; use the live config path only to verify its symlink or when the config is not managed there.
